# HemoLink design system

## Product context

HemoLink is a complete platform for connecting blood donors, people requesting blood, and health organizations. The requested Superdesign project is the source of truth for the product UI and should be translated into the existing React/Vite app.

## Implementation direction

- Use the fetched HemoLink draft as the visual and structural source of truth.
- Preserve an accessible, responsive experience across desktop and mobile.
- Prefer reusable React components for navigation, cards, forms, alerts, status badges, and dashboard sections.
- Keep visual tokens centralized in CSS variables.

## Current repository baseline

The repository is a Vite React starter with system fonts, a neutral light/dark theme, purple accent tokens, and plain CSS. These starter styles may be replaced by the approved HemoLink design.
